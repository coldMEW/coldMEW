## 🛠️ Things I've built

| Project | What it is | Stack |
| --- | --- | --- |
| [**Hush**](https://github.com/coldMEW/Hush) | Android app that skips Spotify ad breaks without root or a modded app. It spots ads in Spotify's media session and restarts Spotify in the background, even with the phone locked. | Java · Android · Shizuku |
| [**FocusBridge**](https://github.com/coldMEW/Focusbridge) | Brings important phone notifications to your Windows desktop, with end-to-end encrypted relay sessions and one shared Rust crypto engine for both sides (JNI on Android). | Kotlin · Rust · Tauri · React |
| [**RecastLM**](https://github.com/coldMEW/RecastLM) | Research toolkit for analysing and editing refusal behaviour in language models: activation steering, weight editing and config sweeps. | Python · PyTorch · Transformers |
| [**BaChat**](https://github.com/coldMEW/BaChat) | Privacy-first personal finance app that spots impulse spending and connects budgeting with investing. 🥈 Took 2nd place at a hackathon. | Next.js · TypeScript · IndexedDB |
| [**Crawl**](https://github.com/coldMEW/Crawl) | A terminal maze written from scratch in x86 assembly. Just registers, memory and you. | NASM x86 |
